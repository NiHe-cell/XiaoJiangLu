### 2.3 氛围基调

- **基调**：热闹、明快、不阴森 —— 夜里点了灯的东汉末年戏台。
- **明暗结构**：暗底占 55%+，灯火金点缀 10%，形成"暗里透亮"。角色站在暗底上必须有**底部一圈暖色反光边**（模拟台口灯从下补光），否则会"贴不上地面"。
- **静止 vs 触发**：静止时稳（对称、居中、grid 对齐），触发时炸（scale punch + 位移 + 飘字）。**静帧美术只负责"稳"的部分**，动效全部由代码实现。

1. **§4.1 的【风格前缀】必须整段复制**，不要凭记忆改写 —— 凭记忆改写 = 风格漂移的头号原因。

3. **一次只改一个变量**：先全员出"常态"，确认同族一致后再做变体。
4. 同一提示词重试 **不得超过 3 次**；3 次不成走三级降级（改描述 → 简化主体 → 拆件或人工精修）。

### 4.11 生成器已知偏差与对策（实测，v1.1 新增）

| 偏差 | 实测证据 | 对策 |
|---|---|---|
| 纯色底会漂移 | 4 张图 4 个"品红"：`#A71944` / `#E412C5` / `#C71462` / `#BC224D` | 前缀加 `BACKGROUND RULE`；抠图前**逐张实测取色**再 keyout |
| 主体贴边 | 魂火图标左/上边距 **0.0%**；单位立绘右/下 1.1%/0.7% | 前缀明确 `subject must not touch any frame edge` + 8–10% margin |
| 会画地面投影 | 关羽立绘脚下有椭圆阴影落在背景上 | 前缀加 `do not draw any ellipse or shadow under the feet` |
| 头身比偏大 | 要求 1:1.6，实测约 1:2.5（偏半 Q） | 改用可量测口径：`head including helmet occupies 45% of the total figure height` |
| 描边色漂移 | 魂火=深紫、双剑=橄榄绿、头盔=深墨 | 前缀加 `OUTLINE RULE`，全族锁定 `#2B2B33` |
| 背景类过暗 | 战斗背景主色板 `#23222C`/`#24232E` 占绝对多数，金色缺席 | 前缀加 `BRIGHTNESS FLOOR`，要求至少 3 处暖金光池 |
| 图标主体偏小 | 出征图标主体仅占 61.8% | 统一要求"主体占画面 70–75%" |
| 工具水印 | 6/6 张右下角有角标 | 后处理裁掉下缘 3–4% 或局部修补 |
| 同秒并发会撞文件名 | 前两张概念图被写入同一文件名，后一张覆盖前一张 | **串行生成**，不要并发提交；生成后立即重命名 |

## 5. 落地约束（工程侧）

### 5.1 后处理链路（可复现，不许"生成即入包"）

```bash
# 1. 纯色底 → 透明底
python art_asset_tools.py keyout hero_1012_unit_v1.png --color "#FF00FF"
# 2. 裁掉透明边（省显存与图集空间）
python art_asset_tools.py trim ./out
# 3. 主色板提取（校验是否落在色板内）
python art_asset_tools.py palette hero_1012_unit_v1.png
# 4. 接触表：把所有武将拼成一张做缩略图测试
python art_asset_tools.py sheet ./out
# 5. 规格与命名合规校验
python art_asset_tools.py check ./out
```

> 导出时四周留 **1–2px 透明缓冲**，否则图集里会出现相邻图纹理溢出的红绿杂色块。

## 6. 必须人工精修的部分（不谎报"可直接商用"）

| 类别 | 精修项 | 原因 |
|---|---|---|
| 全部单位立绘 | 手部、武器握持、甲片接缝 | AI 在小手与复杂握持上极易出错，Q 版简化后仍需人工重建几何 |
| 脸部 | 眼距、高光点位置统一 | 24 张脸必须同一模板，AI 会自然漂移 |
| 描边 | 统一描边宽度与颜色 | 生成描边往往粗细不均，建议生成后**脚本批量重描边**或人工修 |
| 场景背景 | 上 15% / 下 20% 的 UI 留白区 | 生成图会填内容，需人工清出 UI 安全区 |
| 九宫格件 | 中间可拉伸区的纯净度 | 中间有纹样会导致拉伸变形 |
| 特效 | 加法叠加的纯度 | 需确保背景为纯黑、无灰边 |
