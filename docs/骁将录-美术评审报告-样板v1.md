## 0. 结论：**方向 A 成立，但生成链路有 3 个方法级缺陷必须先修**

方向 A（灯火戏台 · 硬边平涂 Q 版）在 6 张样板里**风格可辨认、同族感成立** —— 平涂无渐变、深墨描边、点状眼、暖金 + 靛青的配色逻辑都跑通了。**方向不需要换。**

但有 3 个问题会**在批量阶段放大成灾难**，必须在批量前修掉：

| # | 方法级缺陷 | 证据 | 后果 |
|---|---|---|---|
| **M1** | **纯色底不是纯色** —— 4 张图 4 个不同的"品红" | 实测背景色：`#A71944` / `#E412C5` / `#C71462` / `#BC224D` | 用统一色值 `keyout` 会**抠不干净**，边缘留残色。必须逐张取色 |
| **M2** | **主体贴边** —— 安全边距普遍不达标 | 单位立绘右/下 1.1%/0.7%；魂火图标左/上 **0.0%** | 抠图后主体被切；入图集时四周无缓冲 → 相邻图纹理溢出（红绿杂色块） |
| **M3** | **右下角工具水印** —— 6 张全部带 `AI生成 WORKBUDDY` 角标 | 目视 6/6 | 违反"无文字/水印"自检项，直接入包即违规 |

## 3. 修正后的提示词增量（v1.1，直接替换 v1.0 §4 的对应段）

### 3.1 【风格前缀】增补句（追加在 v1.0 前缀结尾）

```text
BACKGROUND RULE: flat uniform background with absolutely no vignette, no color shift, no gradient, no cast shadow on the background, subject must not touch any frame edge.
OUTLINE RULE: outline color is always the same dark ink #2B2B33 on every element, never a colored or metallic outline, the warm gold edge belongs only to the top surfaces as a 1-2px bevel highlight.
```

**中文**：`背景必须绝对均匀、无暗角、无色彩偏移、无渐变、主体不得投影到背景上、主体不得触碰画面边缘；轮廓线全部为同一深墨色 #2B2B33，禁止彩色或金属色轮廓；暖金只允许出现在顶面 1-2px 斜切高光边上。`

### 3.2 背景类资产的**独立规则**（v1.0 的漏洞，本版修正）

v1.0 §4.2 要求"四周 8–10% 安全边距"，这条**只适用于前景资产**（角色 / 道具 / 图标 / 特效）。背景类必须铺满：

| 类别 | 边缘规则 | 留白规则 |
|---|---|---|
| 前景资产（hero_* / icon_* / fx_* / ui_*） | 四周 8–10% 安全边距，**绝不贴边** | — |
| 背景类（`bg_*`） | 左右**铺满至边缘**（0%），不裁 | 上 15% / 下 20% 保持**低对比、低明度、无主体**，供 UI 叠加 |

### 3.3 战斗背景（重做）修正提示词关键差异

在 v1.0 §4.5 基础上追加：

```text
BRIGHTNESS FLOOR: the overall image must stay in the mid-dark range, never near-black, keep a visible indigo #1E2A3C to #2C3B52 ambient level across the whole frame, add at least three warm lantern or campfire glow pools in warm gold #F5C451 so the gold accent is clearly present.
SUBJECT READABILITY: at least one recognizable stage or camp structure silhouette must be readable in the mid ground.
```

**中文**：`整体保持中暗调，禁近黑，全画面维持可见的靛青环境明度（#1E2A3C–#2C3B52）；必须至少有 3 处暖金灯火/篝火光池，让金色明确在场；中景必须有可辨认的台口或营寨剪影。`

### 3.4 单位立绘的头身比收紧（替换 v1.0 §4.2 通用段）

```text
PROPORTION: head including helmet must occupy 45% of the total figure height, body and legs together only 55%, extremely chibi, large head, short limbs.
NO GROUND SHADOW: do not draw any ellipse or shadow under the feet, the background stays perfectly flat.
```

**中文**：`头（含盔）必须占全身高度的 45%，躯干与腿合计 55%，极端大头短肢；脚下禁止画任何椭圆阴影或投影，背景保持完全平坦。`

> 说明：v1.0 写的 1:1.6（头占约 40%）在实测中被生成器理解成"半 Q"（实测约 1:2.5）。**锚点数值不改，改的是给生成器的执行口径**——用"头占 45% 总高"这种可直接量测的描述，比"1:1.6"更可控。

## 4. 生成链路的固定作业顺序（修正 M1 / M2 / M3）

```bash
# 步骤 1：生成（纯色底，见 §3.1 规则）
# 步骤 2：逐张实测背景色（不要假设是 #FF00FF）→ 修正 M1
python check_samples.py            # 或 art_asset_tools.py palette <img>
# 步骤 3：用实测色做抠图
python art_asset_tools.py keyout <img> --color "<实测色>"
# 步骤 4：裁透明边 + 四周补 1-2px 透明缓冲 → 修正 M2
python art_asset_tools.py trim <dir>
# 步骤 5：去除右下角水印（裁掉下缘 3–4% 或局部修补）→ 修正 M3
# 步骤 6：缩到规格尺寸（源图 2 倍 → 目标尺寸）
# 步骤 7：接触表复查 + 规格合规校验
python art_asset_tools.py sheet <dir> && python art_asset_tools.py check <dir>
```
