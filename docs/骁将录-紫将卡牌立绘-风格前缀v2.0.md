## 5. 与既有规格的冲突（必须处理，否则 UI 与角色会打架）

| 冲突项 | v1.0 已确认（UI 侧） | v2.0 本次（角色侧） | 影响 |
|---|---|---|---|
| 渲染语言 | 平涂 + 3px 深墨描边，**禁渐变** | 高饱和厚涂 + 体积光影 | 同屏割裂：厚涂角色压在平涂 UI 上会"贴不上去" |
| 主色 | 暖金 `#F5C451` 为**唯一强调色** | 紫色 `#A96BE0` 为主色 | 色彩重心冲突 |
| 比例 | 1:1.6 Q 版大头 | 1:7 半写实 | 150×180 单位卡内，半写实角色会看不清五官 |
| 资产规格 | 单位立绘 300×360、头像 256×256 | 卡牌立绘含边框光效，是"整卡"而非"透明角色" | 现有 §3.1 规格表已不适用 |

**如果要成套，UI 侧必须同步改的三件事**：
1. **单位卡**：战场 150×180 小卡继续用 **Q 版**（半写实缩到 150px 高必然糊）；卡牌详情 / 图鉴 / 招募演出用 **v2.0 厚涂立绘**。即"两套比例 + 一套配色"，不是一刀切换。
2. **主色让位**：UI 主色由暖金改为「**紫将紫 `#A96BE0` + 暖金 `#F5C451`**」双主色，金银降为描边与高光。
3. **品质色系重排**：现有 6 档品质色（绿/蓝/紫/橙/红/金）需按 v2.0 的紫框造型统一重做框体，紫将框 = 本次产出样式。
