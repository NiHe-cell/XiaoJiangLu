# 像素占位素材（临时管线）

核对日期：2026-11-14。只收了下面这些能在界面里看见的小图，没有整包入库。

## 这批图是什么

Q 版 / 半 Q 版三国立绘仍然是目标。在那批立绘可商用、可进包之前，用 CC0 像素图先把背包、商店、资源条、底栏和战斗站位补上。像素图是临时占位，不是 Q 版立绘，也不满足 `docs/骁将录-四人紫将统一立绘规格-v3.0.md`，不能拿去交差。

加载入口是 `assets/scripts/core/Art.ts` 的 `paintPixel`。面板按 `assets/scripts/data/PixelArtConf.ts` 里的 id 要图。`resources.load` 失败、id 不存在，或 `resolveArt` 认为文件不在时，已经画好的 `Graphics` + `Label` 留在原地，不挂空的 `Sprite`。

文件放在 `assets/resources/pixel/`。Cocos 的 `resources` 目录默认打进微信主包，所以这里只能放登记过的小图，不能把整包 zip 丢进来。贴图 meta 使用 nearest 过滤，并且 `packable: false`，避免图集把像素边缘糊掉。运行时还会再设一次 nearest。

## 包体

源 PNG 合计不到 16KB（`node --experimental-strip-types tools/check-pixel-art.mjs` 会打印精确字节）。`.meta` 是编辑器侧车文件，不进游戏包。

本环境没有 Cocos Creator，没有跑微信小游戏构建，所以这不是主包实测。构建后的贴图 json 会比源 PNG 大一些，按这批体积看仍是几十 KB 这一档，不是 MB。主包 ≤ 4MB 的上限没有放宽，真机包体仍要在有编辑器的机器上重测。

## 许可

三份都是 CC0 1.0。法律上可以不署名。设置页「署名」仍列出作者，方便审核时一眼看到来源。本批没有 CC-BY，因此没有「必须署名」的义务。没有使用 CC-BY-NC、来源不明的转载，或未证实可商用的三国素材。

| 作者 | 作品 | 许可 | 署名 | AI | 来源 |
|---|---|---|---|---|---|
| Pixel Archer | Chinese Icons | CC0 1.0 | 不是必须 | 来源页没有写是否使用生成式 AI | https://opengameart.org/content/chinese-icons |
| OwlishMedia | RPG UI Icons | CC0 1.0 | 不是必须 | 2018 年发布，来源页没有写生成式 AI | https://opengameart.org/content/rpg-ui-icons |

像素没有改色，只做了裁格。Owlish 的白剪影在深色按钮上会乘成浅金色，在金色选中态上乘成深色，这是运行时染色，没有改文件。

## 界面挂在哪

- 资源条：铜钱 / 宝玉 / 寿桃。图还没到时，原地留一个同色圆点，文字仍在。
- 底栏：城门、盾、盔、桃花、口袋。图还没到时留一个小色块，文字仍在。
- 主城：出征用交叉剑，招募用桃花，商城用元宝，日常用钟。
- 招募台顶部：桃花、宝玉、卷轴。缺图时这块保持原来的纯色台子。
- 背包和商店：按道具类型和装备槽取图。格子上的品质色块就是缺图时的样子。
- 武将卡和战斗单位：职业替身盖在个人主色上。缺图时露出色块和原来的类型纹样。敌方用 `foe`。

设置 → 署名，读的是 `creditPages()`，和本文件同一份作者数据。

## 缺图时怎么验

```bash
node --experimental-strip-types tools/check-pixel-art.mjs
```

脚本会确认每张登记过的 PNG 都在，并且 `resolveArt(id, () => false)` 得到 `fallback`。把铜钱从「还在的文件」里拿掉再问一次，结果也是 `fallback`。这就是 `Art.ts` 在 `resources.load` 失败时走的同一条判断。

真机或编辑器里要看画面：删掉 `assets/resources/pixel/coin.png` 后重新进游戏，资源条仍应画出金色圆点和「银币」数字，而不是一个空方块。测完把文件加回去。

## 看过但没有入库

- nessava，Ancient Chinese Character Pack 1，CC0。整包约 3.3MB，单张约 120–200KB，画布是大正方形，不是小像素图标。
- itch 上标明 AI 辅助的武侠武器、护身符、仙侠包。本批不用。以后若要用，必须在本文件和设置页写明 AI。
- 爱给网转载、商业游戏拆包、CC-BY-NC，以及 itch 上没有写清可商用许可的「像素三国」类素材。不用。

## 再加一张图时

1. 确认来源页的许可是 CC0，或至少允许商用并且署名义务写得清楚。不要用 NC。
2. 只复制会挂到界面上的那几格，压成小 PNG，放到 `assets/resources/pixel/`。
3. 在 `PixelArtConf.ts` 登记 id、路径、`creditId`、出现位置。CC-BY 要把 `attributionRequired` 设为 true，设置页的句子会跟着变。
4. 贴图用 nearest，并且不要打进自动图集。
5. 面板调用 `paintPixel`。缺图时玩家仍然能看懂这块 UI。
6. 更新本文件，再跑上面的检查脚本。
