## 2. 统一规格（四人硬性一致）

| 项 | 规格 |
|---|---|
| 画布 | **1024×1536**（生成源），导出卡面 512×768，头像 512×512 中心裁切 |
| 头身比 | **1:2.5**；头（含冠饰）占全高约 **40%** |
| 视角 | 全身、正面、**微侧约 15°**、略仰视、平视镜头 |
| 主体占比 | 角色占画面高度 **约 68%**，四周留白 **≥4%**（本次孙权未达标，见 §6） |
| 光照 | 主光**左上方**暖金；右侧冷色轮廓光；背后局部金色光晕贴住角色 |
| 描边 | 内层墨色 `#171B22` 粗描边 + 外层紫色 `#A96BE0` 品质描边（**宽度四人一致**） |
| 背景 | **纯品红底、绝对均匀、无渐变、无暗角**，供抠图 |
| 文字 | **零文字、零数字、零符号、零 logo**（名称与等级全部由 UI `Label` 绘制） |
| 紫色用法 | **只允许**出现在：①角色外轮廓的品质描边 ②卡片细边框。**禁止**出现在服饰、甲胄、武器、头发上 |

## 7. UI 同步调整清单（对应你的第 6 条要求）

**先给结论**：本版 Q 版厚涂路线与你既有的 Q 版 UI 规格（`docs/UI视觉规格-温绘.md`）**同族**，冲突面比上一轮小得多。UI 侧只需改 **2 处**，另加 **3 项落实**。

### 必改（2 处）

| # | 项 | 现状 | 改为 |
|---|---|---|---|
| **U1** | **品质色** | 六档品质色：绿 / 蓝 / 紫 / 橙 / 红 / 金 | 立绘与 UI **共用同一套框体造型**，只换描边色（**代码换色，不出图**）。紫将 = 紫描边 `#A96BE0` + 紫细卡框，与本次立绘一致 |
| **U2** | **阵营色** | 阵营色 `#2E5FD9` / `#D9542F` / `#1FA5A0` / `#8B5CF6` 用于区分阵营 | **从 UI 色板移除**。阵营改用**形状区分**：统一金色单色徽记，魏＝虎、蜀＝龙、吴＝水纹、群＝兽面。否则去色后玩家在列表里无法辨阵营 |

| # | 项 | 做法 |
