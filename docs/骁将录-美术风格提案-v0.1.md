## 0. 结论先行

1. **推荐方向 A「灯火戏台 · 硬边平涂 Q 版」**。三条理由：与已有 UI 色板 100% 同源（不会 UI 一套、角色一套）；88×88 图标与 150×180 单位卡尺寸下可读性最好；AI 生成的风格漂移最小，可控性最高。
2. **必须先拍板一个冲突**：`GAME.md` §6 与 UI 规格 R1 红线写明「**零外部美术资源**」（`assets/` 下不得出现 `.png/.jpg/.atlas/.plist/.sk/.ttf`）。**在此红线生效的前提下，本提案里任何"贴图资产"都不能进包体**。见 §3 Q1。
3. **包体是硬约束，不是软建议**：微信小游戏主包上限 4MB、总包 20MB（**需按当前平台政策实测复核**）。26 武将全套立绘若走真贴图，主包装不下，必须提前定加载策略。见 §3 Q2。

## 2. 三个可行方向对比

### 方向 A · 灯火戏台 · 硬边平涂 Q 版（推荐）

**风格锚点（5 个）**

| # | 锚点 | 作用 | 适用边界 |
|---|---|---|---|
| A1 | **东汉末年夜戏台** | 界定取材范围：汉末服饰甲胄（深衣、两当铠、幘冠）、场景道具（战鼓、旌旗、灯笼、案几） | 不做历史考据级还原；甲胄简化为几何块面；不出现明清样式（如补子、顶戴） |
| A2 | **硬边平涂 + 2–4px 深色描边** | 保证 88px 图标、150×180 单位卡在缩略图下认得出 | 禁渐变、禁柔边笔刷、禁描边粗细抖动、禁外发光糊边 |
| A3 | **纸雕 / 木刻质感** | 用「面块 + 顶部 1–2px 高光边」造体积，替代引擎不支持的渐变 | 不做金属镜面高光、不做写实布料纹理、不做照片贴图 |
| A4 | **1:1.6 大头身比 + 点状眼** | 与 UI 规格 §1.1 完全同源；表情只靠眼形切换（常态 / `> <` 受击） | 不做写实五官、不做表情贴图、不做嘴部细节 |
| A5 | **暖金灯火 + 靛青暗底** | 单一暖光源自左上打光，底压低饱和，金 `#F5C451` 跳出来 | 禁冷光阴森调、禁大面积纯黑、禁惨白（白降级为米宣 `#F2EADC`） |

**代价与风险**：视觉冲击力上限偏低，容易"货架感"，与市面三国卡牌差异化不足（靠玩法与竖屏单手体验补足）。

---

### 方向 B · 水墨重彩 · 半 Q 版国风

**风格锚点（5 个）**

| # | 锚点 | 作用 | 适用边界 |
|---|---|---|---|
| B1 | **宣纸底 + 水墨晕染边缘** | 建立国风辨识度，宣传图/立绘表现力强 | 晕染 = 透明通道毛边，88px 图标会糊，需单独做"硬边版"图标 |
| B2 | **毛笔勾线粗细变化** | 线条有提按，画面有书写感 | 与现有「统一 2–4px 硬描边」的 UI 规格**直接冲突**，UI 需同步改版 |
| B3 | **朱砂 / 石青 / 石绿重彩设色** | 国潮配色，与竞品拉开差异 | 需重做整套色板（现阵营色全部作废），已有 UI 返工 |
| B4 | **1:2.2 半 Q 版身比** | 比 A 更耐看，立绘更有戏 | 大头萌感削弱，与"Q 版萌系三国"定位偏离；150×180 卡内需放大头部占比 |
| B5 | **留白构图 + 散点透视** | 场景有气韵，不塞满 | 竖屏小屏留白 = 信息密度下降，卡牌列表页会显空 |

**代价与风险**：AI 生成一致性最差（每张墨迹走向不同，26 个武将容易变成 26 种画法）；UI 全量返工；透明通道毛边需额外修边工序。

---

### 方向 C · 皮影剪纸 · 极简剪影

**风格锚点（5 个）**

| # | 锚点 | 作用 | 适用边界 |
|---|---|---|---|
| C1 | **皮影剪影轮廓** | 剪影可读性天然极强，缩略图测试稳过 | 武将辨识度全押在剪影设计上，设计功力不够就会"人人一个样" |
| C2 | **单色平涂 + 镂空纹样** | 单色 + 蒙版换色即可复用，资产体量最小 | 稀有度（SSR 金光）表现手段受限，需靠外框/特效补 |
| C3 | **暖光透色（琥珀 / 朱红）** | 皮影灯箱质感，氛围独一无二 | 暗底 + 透光的对比关系与现有 UI 明度阶梯需重排 |
| C4 | **程式化正脸 / 侧脸** | 造型统一，批量生产成本最低 | 表情与个性表达弱，羁绊演出的情绪传达受限 |
| C5 | **强负空间** | 画面干净，包体友好 | 竖屏卡牌需要"满"的货架感，负空间过多会显简陋 |

**代价与风险**：卡牌游戏靠"品质感"驱动付费与收集欲（本项目虽无付费，但有养成驱动），单色镂空难撑稀有度；且不改现有 UI 则整体割裂。

### 2.4 三方向打分对比

| 评判维度 | 权重 | A 灯火戏台 | B 水墨重彩 | C 皮影剪纸 |
|---|---|---|---|---|
| 小尺寸可读性（88px / 150×180） | 高 | **5** | 2 | 4 |
| 与现有 UI 规格同源度 | 高 | **5** | 1 | 2 |
| AI 生成一致性（26 个武将同族） | 高 | **5** | 2 | 4 |
| 视觉差异化 | 中 | 3 | **5** | **5** |
| 包体友好度 | 中 | 3 | 2 | **5** |
| 稀有度 / 品质感表达 | 中 | **5** | 4 | 2 |
| 落地风险（返工量） | 高 | **5**（零返工） | 1（UI 全量返工） | 2（UI 半量返工） |
| **加权结论** | | **推荐** | 备选（需接受 UI 返工） | 备选（适合小规模验证） |

> 打分口径：5=最好，1=最差；权重为本项目竖屏小屏 + 零资源现状下的判断。
