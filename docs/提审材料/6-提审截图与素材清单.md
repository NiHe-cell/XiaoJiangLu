## 3. 游戏简介文案（成稿）

> 用于 mp 后台「游戏介绍 / 游戏内容说明」。平台要求：**须填写能体现游戏内容和玩法的实质性内容**，包含背景、扮演角色、场景、主要情节、玩法、功能（系统）、主要特点、使用方法等，**不得上传无关通用模板或感受类内容**。

### 3.1 完整版（提审「游戏内容介绍」用，约 500 字）

**《骁将录》是一款以三国时期为背景的竖屏卡牌收集与回合制策略小游戏。**

玩家扮演一位初登乱世的诸侯，通过招募名将、编练阵容、征讨关卡，逐步壮大自己的势力。

**核心玩法：**

- **武将收集**：游戏共设 24 名武将，分属不同阵营与职业（输出、防御、辅助）。玩家可通过招募系统获取武将，集齐指定武将可激活羁绊，获得额外属性加成。
- **回合制战斗**：战斗采用自动回合制，双方最多上阵多名武将，按速度顺序行动。玩家需在开战前编排站位与阵容，利用阵营光环、羁绊联动与职业搭配形成策略优势。
- **关卡征讨**：游戏共设 63 个关卡，分 6 章推进，难度逐步提升。关卡设星级评定，达成条件可获得额外奖励。
- **武将养成**：武将可通过升级、进阶、升星、穿戴装备四条线提升战力，养成节奏平缓，不设付费墙。
- **日常玩法**：每日签到、七日任务与经验/银币/进阶丹三类日常副本，为玩家提供稳定的成长产出。

**主要特点：**

- 竖屏单手操作，适配碎片化时间；
- 全中文 Q 版美术风格，画面简洁明快；
- 无充值、无内购，全部内容可通过游戏内玩法获得；
- 低养成压力，不设强制任务与强制分享。

**使用方法：** 进入游戏后跟随新手引导完成首战，随后可在主城界面选择关卡征讨、武将养成、招募等功能入口，自由安排游戏进程。

### 3.2 精简版（商店/分享副标题用，≤ 60 字）

> 三国名将收集 × 回合策略。24 武将、63 关卡、羁绊阵营搭配，竖屏单手，全免费无内购。

### 3.3 一句话版（≤ 20 字）

> 收三国名将，打回合策略，全程免费。

## 5. 测试账号说明（版本更新说明 + 测试指引）

> 微信提审需提供「**版本更新说明**」及便于审核人员验证的信息。本项目无需账号登录，但必须把"审核人员怎么验证"写清楚。

### 5.1 版本更新说明（首次提审模板）

```
版本：1.0.0
更新内容：
1. 首发版本上线，包含 24 名武将、63 个关卡（6 章）；
2. 开放武将养成系统（升级、进阶、升星、装备）与招募系统；
3. 开放每日签到、七日任务与三类日常副本（经验/银币/进阶丹）；
4. 新增新手引导（5 步），保障首次进入即可上手；
5. 新增设置页：意见反馈入口、《用户隐私保护指引》与《用户服务协议》入口、适龄提示与健康忠告；
6. 接入广告（激励视频/插屏/Banner），广告加载失败不影响游戏进程。
```

### 5.2 审核测试说明（给审核人员看）

```
测试方式：
- 本游戏无需注册账号，进入即玩，无登录门槛。
- 首次进入将展示《用户隐私保护指引》授权弹窗，可选择"不同意"，
  游戏本地玩法仍可正常进行（仅暂停广告展示）。
- 建议体验路径：开始页 → 新手引导（5 步） → 主城 → 出征（关卡1-1）
  → 战斗 → 武将 → 养成 → 招募 → 设置。
- 引导与关卡数值已做平缓处理，审核人员可在 3 分钟内完成前 3 关。
- 如遇问题，可通过「设置 → 意见反馈」提交。
```

> 💡 **给审核人员写"建议体验路径"是低成本高收益的动作**——审核人员的耐心是有限的，路径写得越清楚，被判"内容简单/玩不懂"的概率越低。
